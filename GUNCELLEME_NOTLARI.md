# V-TANEX Güncelleme

Bu paket mevcut V-TANEX dosyalarının üzerine yüklenir. `index.html`, `plants.json`, eski localStorage anahtarı ve kayıtlar korunur.

- Ana sayfaya Yürüyüş kartı eklendi. Sağlık içinden de erişilir.
- Sağlık, Beslenme, Eğitim, Sosyal Yaşam, Kişisel Gelişim ve İş/Kariyer bölümleri ayrı tarihli kayıt formları, özetler ve geçmiş listeleriyle geliştirildi.
- Raporlar sayfasına bölüm bazında kayıt sayıları eklendi.
- JSON yedekleri yürüyüş geçmişi ve yürüyüş ayarlarını da kapsar.
- Servis çalışanı önbelleği v4 olarak yenilendi.

## iPhone GitHub yükleme

Depo: https://github.com/trocki59-byte/V-TANEX

Depodaki aynı adlı dosyaları güncelleyin. ZIP dosyasını doğrudan web sitesine koymayın; içindeki dosyalar deponun kök dizininde olmalıdır. GitHub Pages `main` / `(root)` kullanır.

## Sınırlar

GPS konum takibi iPhone Safari arka plandayken kesilebilir. Adım sayısı tahminidir. Bildirimler uygulama kapalıyken sunucu push altyapısı olmadan garanti edilemez. Sağlık verileri bu cihazın yerel depolamasında saklanır; düzenli yedek alın.
